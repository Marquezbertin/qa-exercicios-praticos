# Artifact Package — Quality and Defects in AI-Generated Software (anonymized)

> **Anonymized version for double-anonymous review.** Do not include author-identifying information. This package corresponds to the manuscript submitted to the SBES Research Track (2027 cycle).

## What is this

This package contains the **aggregated data and reproducible generation script** for the figures and tables of the study **"Empirical Evaluation of Quality and Defects in Software Generated by AI Agents: A Comparative Study under Controlled Requirements"**.

- `figuras/` — the five figures of the manuscript (PNG):
  - `fig1_densidade.png` — defect density per agent (defects/KLOC)
  - `fig2_heatmap_categoria_agente.png` — defect category × agent heatmap
  - `fig3_bootabilidade.png` — bootability and oracle pass rate
  - `fig4_kappa.png` — inter-rater agreement (Cohen's κ)
  - `fig5_severidade.png` — severity distribution
- `gerar_figuras.py` — script that regenerates the figures from the aggregated data embedded in the source (no external datasets required)

## Requirements

- Python 3.9+ (tested with 3.12.0)
- Third-party libraries used by the script:
  - `matplotlib`
  - `numpy`
  - `scipy` (for statistical annotations)

Install with:
```
pip install matplotlib numpy scipy
```

## Installation

1. Clone/copy the contents of this package into any local directory.
2. Keep the file `gerar_figuras.py` at the same level as the `figuras/` directory (the script writes output there by default; if it writes to another path, pass it via the script's command-line argument or edit the output constant as documented in the script header).
3. Run:
```
python gerar_figuras.py
```
4. The five PNGs will be (re)generated. Compare them with the ones in `figuras/`; they must match the figures in the manuscript.

## Organization of the experiment data

- **This package:** aggregates only (counts, densities, contingency tables, κ) and the figure script. No raw code, no credentials, no private execution infrastructure.
- **Not included (by design), with justification:**
  - the **specification and independent oracle suite** — internal reference artifacts of the study, kept private during review to preserve double-anonymous review; to be disclosed as a curated, credentialed version after acceptance;
  - **raw execution logs** — contain environment and application credentials; restricted permanently;
  - **full defect matrix** — internal analysis document; available in summarized form in the manuscript's tables.
- Reviewers who need the summarized tables in machine-readable form can reconstruct them with the script (the script embeds the aggregates).

## Reproducibility statement

All numbers and figures in the manuscript are reproducible from this package alone: the script contains (or reads) every aggregate value used in Sections 4–5 (densities, pass rates, category contingency table, severity counts, κ values, Fisher/χ² statistics as annotations). Storage needs: < 1 MB.
